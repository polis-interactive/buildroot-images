# Repository instructions

## Makefile and command help

- Keep `make help` synchronized with Makefile changes. When adding, removing,
  renaming, or changing the behavior of a user-facing target, update its help
  entry in the same change, including help generated by `src/cli.py` where relevant.
- Describe what cleanup targets delete using their actual paths.
- Before finishing a Makefile change, run `make help` and check that the affected
  commands and descriptions are present and accurate, with no stale entries.
